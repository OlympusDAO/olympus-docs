**Title:** ERC7528Constants

Constants defined by EIP-7528 for representing the native asset in interfaces
that otherwise expect an ERC20 address.

<i>

See [https://eips.ethereum.org/EIPS/eip-7528](https://eips.ethereum.org/EIPS/eip-7528).

</i>

## Constants

### NATIVE_ASSET

Sentinel address representing the native asset.

```solidity
address internal constant NATIVE_ASSET = 0xEeeeeEeeeEeEeeEeEeEeeEEEeeeeEeeeeeeeEEeE;
```
